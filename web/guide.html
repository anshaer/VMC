通用 Web 接收診斷

入口：https://anshaer.github.io/VMC/web/receiver.html

共用傳送端：https://anshaer.github.io/VMC/transmit/

接收頁提供連接碼、一維碼、按鈕顯示 QR、多來源分區、面部數值與點線預覽、滑動方向。這頁是資料診斷，不含角色繪圖、角色 ZIP 匯入，也不包含 2D 製作器。接入自己的 2D 網頁時，請使用相同通訊協定與分區邏輯，將資料轉成角色的參數。

共用手機可選面部／上半身／全身；Web 接收數值中的面部為主，完整骨骼資料可由程式取得。滑動不會自動替你切換角色服裝／表情，須在自己的角色頁實作方向對應。
