手機動捕、平板多點控制；傳輸與接收都在線上開啟，六種接收版本。

GitHub 上架包 v1.1 · 網址 https://anshaer.github.io/VMC/

直接開線上接收頁，再連手機／平板

  1. 選下方接收軟體，依說明開啟接收頁與必要插件。
  2. 接收頁產生連接碼，手機鏡頭頁或平板控制頁輸入同一碼。
  3. 啟用辨識與軟體接收。VTS 還須加入參數對應並啟用注入。

共用功能

掃描／輸入連接碼、一維碼、按鈕顯示 QR、最多 8 台分區接收、滑動方向、資料逾時釋放與目前狀態顯示。各軟體能套用的動作與快捷鍵不同，請看專屬說明。

Web 區為接收診斷；不含角色渲染或 2D 製作器。VTS 控制 Live2D 輸入參數，不等同完整 3D 骨架動捕。
