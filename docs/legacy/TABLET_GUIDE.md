# VMC 平板控制端 v1.1

平板用滑桿與按鈕產生動作資料，不使用相機、不載入辨識模型。

| 用途              | 頁面                                                                |
| ----------------- | ------------------------------------------------------------------- |
| 2D 面部／頭部     | [2D Web 平板端](https://anshaer.github.io/VMC/transmit/tablet.html) |
| Warudo 面部／骨骼 | [Warudo 平板端](https://anshaer.github.io/VMC/transmit/tablet.html) |

## 連線

1. 電腦開對應的 receiver.html；Warudo 用途先連好插件。
2. 平板開 tablet.html，輸入電腦接收頁的 12 碼，按連線。
3. 成功後開始傳送目前滑桿／按鈕數值。資料為手動合成，不是真人辨識。
4. 此版用輸入碼配對，沒有掃描相機功能。PeerJS 配對仍需網路。
5. 新版接收頁可同時配對最多 8 台；選面部／身體等各自區域，詳見 [分區控制](https://anshaer.github.io/VMC/docs/MULTI_TABLET.md)。

## 多點觸控

每個滑桿獨立追蹤 pointerId，可以同時拖動不同滑桿並按住表情按鈕。
同一滑桿只接受一個觸點。相同資料欄位若被多個控制項調整，按住按鈕暫時覆蓋底值；多個按鈕改同欄位時後按的優先，放開後恢復仍按住的設定或底值。

- 滑桿預設放開後保持。
- 分別勾「面部放開歸零」或「身體放開歸零」後，放開／取消／失焦回預設；深度回 1，其餘回 0。此版立即回歸，不是平滑回彈。
- 「表情／姿勢按鈕按住生效」預設勾選；放開回到底值。
- 取消該勾選後，按鈕直接寫入數值，保持直到再調或歸零。
- 支援觸控、滑鼠及鍵盤方向鍵；數值框可直接輸入。
- 頁面失焦或隱藏會釋放按住狀態，關頁會停計時器及連線。

預覽預設收合；展開為小畫面，收合時不繪製。

## 2D Web 版

轉頭、抬低頭、歪頭、閉眼、張嘴、嘟嘴、微笑、眉毛與視線。
深度是 ANSHA 自訂面部大小訊號，不是一般 VMC 的相機距離。
本機顯示數值，接收診斷頁顯示收到的頭部／表情；不會產生相機臉部關鍵點。
服裝／表情按鈕傳上／下／左／右事件；是否切換取決於正式角色頁的切換邏輯。

## Warudo 版

在面部功能之外，加入根節點 XYZ 位移與骨骼局部角度。

- 四個控制槽可分別選任何已包含的骨骼，同時控制左右上臂／前臂，或改選手掌、腿、腳與單獨指節。
- 骨骼 XYZ 使用角度，輸出四元數；Head 使用面部轉頭滑桿。
- 全身輸出 51 根骨骼（含頭及 30 指節），採通用 1.6 公尺參考骨架位置；不是讀取模型的原始綁定骨架。
- Root 位移範圍 -1..1 公尺，輸出根旋轉維持單位旋轉；身體轉向可在 Hips／Chest 控制槽調整。
- 有 T 姿勢、垂臂、左右招呼的靜態預設，不是循環動畫。
- 十指握拳快捷將該指三節設定為通用彎曲角度；會覆寫該指單節細調，兩者不疊加。
- 模型方向不一致時，在 Warudo 插件做骨骼方向校正。預設姿勢不是所有模型都相容。
- 方向事件要連接 Anshaer_Web_Vmc On VMC Swipe 藍圖；插件收到不代表衣服已切換。

## 姿勢保存

保存／載入：本分頁保留一份底值姿勢，關頁後釋放；按住中的暫時覆蓋不保存。
匯出／匯入：JSON 保存滑桿與骨骼底值。2D/Warudo 文件不能互相匯入，檔案上限 64KB。
連接碼、Access Key、連線與觸點不會寫入姿勢檔。

## 暫停與限制

暫停傳送會保持連線，但不送動作；接收端可能保持最後姿勢，不能假設一定回中性。
全部歸零會清除底值和按住狀態；若仍連線及傳送，接收端會收到新的中性資料。
支援多平板分區控制，不是多鏡頭融合；尚無攝影機掃描、時間軸、平滑過渡或動作循環。

## 驗證

兩個實際 HTML 的控制程式在 DOM 測試環境通過：配對與 OSC 接收、三個同時觸點、取消／歸零、表情覆蓋、指節與根位移、方向確認、姿勢匯入、暫停、中斷與關頁清理。
生成的兩種封包也通過實際 C# 插件的 WebSocket → UDP 原樣轉送測試。Warudo API 使用測試替身。
尚未在實體 iPad／Android 平板、真實 Warudo 模型上完成測試。
